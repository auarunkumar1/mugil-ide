# Signature Remover Module

Removes boilerplate "signatures":
- **Prompt side** — Anthropic `Human:`/`Assistant:` markers, `<system>` tags
  and "You are Claude…" preambles; OpenAI "As an AI language model…" preambles;
  generic gratitude closers and disclaimers.
- **Code side** — AI attribution headers ("// Generated by Copilot"), standalone
  AI-attribution comment lines, and invisible watermark characters (zero-width
  spaces, BOM).

**Credits:** the prompt rules target signature formats introduced by Anthropic
and OpenAI; the code rules are inspired by community "de-AI" tooling such as
[conorbronsdon/avoid-ai-writing](https://github.com/conorbronsdon/avoid-ai-writing)
and [wiltodelta/remove-ai-watermarks](https://github.com/wiltodelta/remove-ai-watermarks).
See [ATTRIBUTIONS.md](../../../../ATTRIBUTIONS.md).
