# Watermark Remover Module

Removes AI provenance watermarks from generated text — the invisible
carriers vendors hide in the character stream and the visible attribution
lines they stamp on content.

**Credits:** inspired by
[guillaumemeyer/watermarks-remover](https://github.com/guillaumemeyer/watermarks-remover)
(agent skill + stdlib Python scripts that strip multi-vendor AI provenance
marks from text and files — Claude, Gemini/SynthID-Text, OpenAI provenance
surfaces, open-LLM Kirchenbauer-style marks). This module ports its
deterministic **Layer A** (Unicode text hygiene) to TypeScript. See
[ATTRIBUTIONS.md](../../../../ATTRIBUTIONS.md).

```ts
import { stripWatermarks } from '@mugil-ide/core';
```

## Layer A — deterministic (implemented)

| Carrier | What it is | Example |
| --- | --- | --- |
| Invisible | Zero-width space / non-joiner / joiner, word joiner, BOM, soft hyphen | `U+200B U+200C U+200D U+2060 U+FEFF U+00AD` |
| Bidi / format controls | Directional overrides + isolates, Arabic letter mark | `U+202A–U+202E U+2066–U+2069 U+061C` |
| Tags | Deprecated tag block | `U+E0000–U+E007F` |
| Exotic spaces | NBSP, ogham, en/em spaces, narrow NBSP, math/ideographic spaces | normalized to a regular space |
| Vendor attribution lines | "This response was generated by AI", "Written by Claude", "Powered by ChatGPT", Gemini/SynthID stamps | removed line-by-line |

## Layer B — statistical marks (best-effort, not implemented)

Modern LLM watermarks often hide a signal in **which tokens are chosen**
(sampling bias), not in invisible characters. Stripping that requires
rewriting a substantial fraction of the text sentence-by-sentence (paraphrase
/ back-translation) — a model rewrite pass, not a regex. If you need it, run
the rewrite through a *non-origin* model (rewriting with the origin model can
re-stamp the text) and expect the copy to flatten. No tool can honestly
certify that a vendor detector will fail.

## Responsible use

For content **you own or are authorized to process** — privacy and hygiene,
not academic fraud or false "human-written" claims. The upstream project's
ethics guidance applies here too.
